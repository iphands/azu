## Environment at deferral time

Measured on this host by `scripts/big-fix-env-probe.sh` plus direct PATH probes
(see `.omo/evidence/big-fix/backend-deferral-scaffold.txt` for the raw output;
`required_cpu_lane: pass`):

- nvcc: missing (`command -v nvcc` exit 1, `nvcc --version` exit 127)
- hipcc: present on PATH at `/usr/sbin/hipcc` but not usable as a versioned
  compiler: `hipcc --version` reports `/usr/share/hip/version` not found and
  `/usr/bin/rocm_agent_enumerator` is absent, so the version string is unknown
- CUDA runtime: present at driver level (`libcuda.so.1 => /lib64/libcuda.so.1`,
  `/dev/nvidia0`, `/dev/nvidiactl` exist) — recorded, and still unreachable
  because `nvcc` is absent and this plan forbids CUDA compilation
- HIP runtime: absent at runtime level (no `libamdhip64` in the `ldconfig`
  cache, no `/dev/kfd`) even though the `hipcc` wrapper is on PATH
- libfreenect: present (`pkg-config --exists libfreenect` exit 0; the probe
  field `libfreenect: 0` is a modversion-string artifact, the real soname is
  `libfreenect.so.0.7.5`)
- existing build-cuda/: present — protected; never deleted, cleaned,
  reconfigured, or otherwise mutated by this plan
